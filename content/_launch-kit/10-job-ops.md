# 10 — Job Ops: From Booking to Review (DRAFT for Dre)

The operating manual for every job. One goal throughout: do it safely, price it from the approved sheet, keep every residential job ≤ $1,999, leave with photos and an honest review ask.

---

## 1. Pre-job checklist (night before)

- [ ] Job card printed/phone-ready: name, address, phone, service, sheet price range, access notes (gates, dogs, spigot), preferred date
- [ ] Route + arrival window texted (09 §6 template)
- [ ] Ladder(s) rated for the story height; stabilizer/standoff for gutters; rope and harness for roof work
- [ ] Gear: buckets, scoops, blower, hose + downspout flush fittings, guards stock (for guard jobs — verify linear footage order matches estimate), sealant/hangers/repair kit, PPE
- [ ] Chemicals mixed for soft wash; plants pre-wet plan noted; "wet down plants" step on the card
- [ ] Water source confirmed (spigot location from intake)
- [ ] Weather check — no roof work in lightning or high wind; reschedule call ready
- [ ] Payment method confirmed (card reader/charge, check, invoice)

## 2. On-site estimate script + scope decision tree

**Walk the property with the customer (or start the photo walk if they're not home — always notify first):**

> "Here's what I'm looking at: [gutter runs / siding faces / roof sections]. Based on the sheet, this comes out to $[X] — that's the number in writing before I start. If I find something that changes it, I stop and show you first."

**Scope decision tree (run before quoting, every job):**

```
START: What does the customer actually want?
│
├─ Gutter cleaning?
│   └─ Stories: 1 ($149–$229) / 2 ($199–$299) / 3 ($299–$399) / larger home (+$20–$60)
│      └─ Total ≤ $1,999? YES → quote it. (Cleaning alone will never hit the cap — quote and go.)
│
├─ Guards on existing gutters?
│   └─ Measure linear feet × $12/$14/$16 (1/2/3 story), $599 min.
│      └─ ≤ $1,999? YES → quote in writing.
│      └─ > $1,999? → "NOT OFFERED YET": explain honestly — the job exceeds what we can
│         take on right now; offer: (a) guard the highest-debris runs now within budget,
│         as a clearly separate project the customer chooses, or (b) referral. NEVER split
│         one home's guard job into multiple invoices to sneak under the cap.
│
├─ Repair?
│   └─ $129 service call covers diagnosis + minor fixes on the spot.
│      └─ Repair beyond minor? → quote in writing after diagnosis. Total job (call + repair)
│         still ≤ $1,999 → do it. Anything that would exceed → "NOT OFFERED YET" + referral.
│
├─ House soft wash? → from $299, most homes $299–$749. House wash alone won't exceed the cap.
│
├─ Roof soft wash?
│   └─ 1–2 story → $399–$749 band, quote from sheet.
│   └─ 3 story or complex/very large → BY QUOTE ONLY: "Dre will price this one personally —
│      I'll have him call you before we schedule." Never improvise a 3-story number.
│
├─ COMBINATIONS (roof + guards, wash + guards, whole-home everything)?
│   └─ Add the pieces. Total ≤ $1,999 → one quote, one invoice.
│   └─ Total > $1,999 → "NOT OFFERED YET" for the package as scoped. Offer to phase by
│      service type (wash now, guards next month) — customer's choice, separate jobs,
│      separate invoices, each quoted on its own sheet. NEVER one job split into
│      multiple invoices, and never pressure the phase-up.
│
└─ New gutters / seamless / full replacement / multi-building / commercial-heavy?
   └─ "NOT OFFERED YET" + honest referral. Log as PRIORITY CALLBACK (09 §4).
```

**The exact sentence for "not offered yet":**
> "That's a bigger project than what we take on right now, and I'd rather tell you that honestly than quote it wrong. Here's who I'd call."

## 3. Before/after photo protocol (feeds the 04-video calendar)

Shoot on phone, vertical AND horizontal for key shots. Minimum per job:

1. **Arrival establishing shot** — house from street, truck visible (no address numbers in frame)
2. **Befores** — every gutter run to be cleaned / siding face / roof section (close + wide)
3. **Process** — one "work in progress" shot (scoop, flush, wash fan, guard fit)
4. **Afters** — same angles as the befores, water flowing where relevant
5. **Downspout flush proof** — water exiting clean
6. **Written quote/invoice close-up** — price visible, address blurred
7. **Debris/weird finds** — the "museum" shot (tarp laid out) — these feed Days 3, 9, 16 scripts

Delivery: send the customer 3–5 best before/afters by text with the invoice (they paid for the work; the photos are theirs). Keep everything organized as `[date]-[street]-[service]` so 04-calendar batch-editing takes minutes. Homeowner faces/signs only with explicit permission.

## 4. Service report card fill-in guide

One card per job (phone form or paper). Fill during the job, not after.

| Field | How to fill |
|---|---|
| Date / arrival–departure | Actual times |
| Address + subdivision | Drives route analytics (08 tracking) |
| Service(s) done | Checkboxes; note anything scoped but not done and why |
| Stories / approx. sq ft / linear ft | Drives estimator accuracy over time |
| Sheet price quoted vs. final price | Must match unless change approved on site — if different, note why |
| Condition found | Hangers, pitch, fascia, downspouts, roof stains — one line each |
| Downspout flush result | Flow OK / cleared blockage / needs attention |
| Photos taken | Count + confirm the 7 protocol shots |
| Repairs flagged for future | Customer told? Y/N — seeds the next visit, no pressure |
| Next recommended service + timing | E.g., "fall clean-out" or "guards on rear run" — customer's choice |
| Payment | Method + amount + review-text sent Y/N |

## 5. Review request — one text, 24h after the job

Sent from Dre's number, only after a completed, paid, successful job. No incentive, no discount, no pressure, no "5-star" language:

> Hi [name], Dre with Chaffee Exteriors — thanks again for having me out yesterday. If you have a minute, an honest Google review helps a brand-new local business more than any ad: [GBP review link]. Whatever you write, I appreciate it — and if anything wasn't right, call me first at (479) 492-4232 and I'll make it right.

**Never:** offer anything in exchange for a review, ask only happy customers and cherry-pick, write reviews yourself, have family/friends review without using the service, or bulk-send. If a customer is unhappy, the review ask goes away entirely — the make-it-right call replaces it.

## 6. Membership pitch — 3 sentences, end of job, no pressure

> "One thing before I go: a lot of folks around here do the twice-a-year rhythm — spring and fall. If you'd like, I can put you on the list and text you when your season comes up, same published prices, and you just say yes or ignore it. No contract, no prepayment, no pressure either way."

If yes: log name + preferred season + service in the membership list, first text goes out seasonally. If no/no answer: note it and never re-pitch at the next job — the seasonal text IS the reminder.
